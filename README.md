# Influencer Authenticity vs. AI-Generated Content

Python-based statistical analysis of the main study survey.

## Analysis scripts

- Stage 2: Descriptive statistics, reliability, normality and Harman's test
- Stage 3: Correlations, regression and model diagnostics
- Stage 4: Bootstrapped mediation analysis
- Stage 5: Multivariate normality and regression diagnostics
- Stage 6: Demographic analysis
- Stage 7: Item-level response frequencies
- Stage 8: Final consistency audit

## Sample

The main analysis contains 395 responses and 26 questionnaire items measuring seven constructs.

## Data privacy

Respondent-level data and the original survey export are excluded from this repository. The repository contains analysis scripts and aggregate results only.
